## My approach

I like small teams, fast feedback loops, and products with a strong point of view. My workflow usually moves through:

**Understand → simplify → prototype → test the real interaction → ship → learn**

For AI products, that means making the result legible: showing the work, the evidence, the limitations, and the next action. Simulation is labeled as simulation; sensitive or irreversible actions stay approval-gated.
